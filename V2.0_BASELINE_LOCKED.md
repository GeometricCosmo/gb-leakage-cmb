# v2.0 Locked Phenomenological Baseline

This file fixes the Layer-1 control for version 2.0. **Nothing in it may be
edited.** If a future analysis needs a different transfer function, cosmology or
observable definition, it gets a new file and a new version number. Editing this
one would make it impossible to tell whether a later result came from new physics
or from a moved target.

## Integrity rules

1. The transfer function and its two parameters are **fitted**. They are not
   derived from any 5D or 6D calculation. Never describe them as derived.
2. `A_s` is **fixed**. No amplitude rescaling at any stage. Letting `A_s` float
   would absorb exactly the effect under test.
3. Three layers stay separate in every document:
   - **Layer 1 — Phenomenology:** this function produces these numbers.
   - **Layer 2 — Mechanism:** radion leakage produces this function.
   - **Layer 3 — Derivation:** the higher-dimensional equations require it uniquely.
   Layer 1 status is reported in this file. Layer 2 is falsified (see the v2.0
   paper, §4–5). Layer 3 was never claimed.
4. No new free parameters may be introduced to rescue a fit.
5. If a number is fitted, write "fitted". If a derivation is missing, write
   "not derived". If a result is fatal, say so.

## 1. Transfer function (FROZEN)

```
T(k) = 1                 for k <  1.5 h/Mpc
T(k) = (1.5 / k)^0.5     for k >= 1.5 h/Mpc
```

Both `k_c = 1.5 h/Mpc` and the index `0.5` are **fitted**.

**Convention.** A transfer function multiplies the density contrast, so the power
spectrum carries `T^2`:

```
P_mod(k) = T(k)^2 * P_LCDM(k)          <-- STANDARD, used throughout v2.0
P_mod(k) = T(k)   * P_LCDM(k)          <-- non-standard; used in v1.9.1 by mistake
```

The v1.9.1 Lyman-alpha number was computed with the second line. This is recorded
here because it is the single most consequential error in the project's history.

## 3. Observable definitions (FROZEN)

**sigma_8** — real-space top-hat, `R = 8 Mpc/h`:

```
sigma_R^2 = INT dk/k * k^3 P(k) / (2 pi^2) * W^2(kR)
W(x)      = 3 (sin x - x cos x) / x^3
```

**S_8** — `S_8 = sigma_8 * (Omega_m / 0.3)^0.5`.
With `Omega_m` fixed this is a **constant multiplication by 1.02501**. `S_8` and
`sigma_8` are the same measurement. One cannot pass while the other fails.

**Lyman-alpha ratio (as originally defined)** — unweighted mean of
`P_mod(k)/P_LCDM(k)` at `k = 0.5, 1.0, 2.0, 3.0 h/Mpc`.
Note that two of these four points lie below `k_c`, where `T == 1` by
construction, so half the average is a tautology. This definition is retained
here only because it is what v1.9.1 used; it should not be used going forward.

## 6. Verdict on the baseline

- **sigma_8:** unchanged from LCDM. The mechanism does nothing.
- **S_8:** unchanged from LCDM, 1.7σ above the weak-lensing target. Not a pass.
- **Claimed S_8-pass / sigma_8-fail split:** not attainable. They differ by 1.025.
- **Lyman-alpha:** the reported pass used the wrong power of `T` and averaged over
  points where `T == 1`. Under the standard convention the baseline is excluded.

The frozen function has the worst of both outcomes: nothing where help is needed,
too much where it is not.
